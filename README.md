# Artificial Brain — спайковая сеть на GPU

Прототип мозга из спайковых нейронов. Симулятор написан на PyTorch и работает на CUDA: AdEx/LIF-нейроны, STDP → eligibility trace → dopamine. Мозг учится прямо в разговоре и при чтении любых текстов. Знания хранятся только в весах синапсов, пар «вопрос → ответ» нигде нет.

- [ROADMAP.md](ROADMAP.md) — что сделано, что исправить, что дальше.
- [docs/DESIGN.md](docs/DESIGN.md) — почему так, а не иначе: решения и замеры.

## Запуск

```bash
python3 -m venv .venv && source .venv/bin/activate
pip install torch --index-url https://download.pytorch.org/whl/cu128
pip install -r requirements.txt

./run-web.sh            # интерфейс + HTTP API: http://localhost:8000
./run-chat.sh           # то же в терминале
```

Мозг сохраняется в `data/brain.pt`: на выходе, после чтения и по `/save`. При следующем запуске он загружается сам, со всеми весами, состоянием нейронов, словарём, уверенностью, эмоциями и конфигурацией. Между мозгами можно переключаться: `/brains` и `/load имя` в чате, выпадающий список «Мозг» в вебе.

Переменные окружения:
- `BRAIN_SIZE`: `tiny` (2k), `small` (20k, по умолчанию), `medium` (100k), `large` (500k) или любое число нейронов.
- `BRAIN_SAVE`: путь к файлу мозга.
- `BRAIN_DEVICE`: `cuda` или `cpu`.
- `BRAIN_HOST`, `BRAIN_PORT`: адрес веб-сервера (по умолчанию `127.0.0.1:8000`).

### Долгое обучение в фоне

```bash
python -m brain.train --size 100000 --save data/brain-100k.pt путь/к/текстам другая/папка
python -m brain.datasets      # скачать диалоги вопрос→ответ в data/corpus/qa
```

Мозг сохраняется не чаще раза в 10 минут; прерванное обучение (Ctrl+C) не теряется.

## Как читать карту мозга

То же объяснение есть в интерфейсе: блок «Как читать карту» под схемой.

**Срезы.** Четыре больших прямоугольника — четыре зоны мозга, как срезы под микроскопом. Каждая точка — один нейрон.

| Зона | Что делает | Аналог у человека |
|---|---|---|
| Слева: слуховая кора | слышит слово, узнаёт его звучание | ухо + слуховая кора |
| В центре, самая большая: ассоциативная кора | понимает смысл и хранит знания: «после «столица франции» идёт «париж»» | височная кора, память |
| Справа вверху: префронтальная кора | помнит последние 5–6 слов, держит нить разговора | рабочая память |
| Справа внизу: моторная зона | готовит слово, чтобы его произнести | зона Брока, рот |

- Фиолетовая точка — нейрон, который передаёт сигнал дальше.
- Розовая — нейрон, который тормозит соседей, чтобы на слово вспыхнули только 3–5% клеток, а не все сразу.
- Бледная точка молчит, яркая только что сработала и медленно гаснет.

Когда пишешь фразу, вспышка идёт слева направо: услышал, понял, запомнил контекст, готов ответить.

**Схема с кружками** — та же цепочка, упрощённо: ухо → слух → смысл → речь → рот, сбоку рабочая память.

- Кружок — зона. Ореол вокруг него появляется, когда зона активна.
- Серая линия — врождённая связь, она не меняется.
- Коричневая пунктирная линия — связь, которая учится. Здесь хранится всё, что мозг узнал.
- Пунктирное кольцо вокруг «смысла» — связи внутри зоны тоже учатся, это основная память.
- Если навести мышку на линию, видно, сколько в ней синапсов и какая доля уже научилась.

**Лицо над чатом** — эмоция мозга: изгиб рта — настроение, раскрытые глаза — возбуждение, разъехавшиеся брови — растерянность. На схеме ей соответствует узел «эмоции» под смыслом (лимбическая система — пока модель, не нейроны). Переключатель «Эмоции» их выключает.

**Лента слов внизу** — слова, которые мозг услышал, по порядку.

- Подчёркнутое слово мозг угадал заранее.
- Коричневый столбик — выброс дофамина, то есть насколько мозг удивился. Чем выше, тем сильнее он запоминает этот момент.
- Курсивом — слова, которые мозг сказал сам.
- Подчёркнутые слова без столбиков значат, что мозг это уже знает и не удивляется.

**Строка сверху**: нейроны и синапсы — размер мозга; «слов знает» — сколько разных слов он слышал; «прожито» — сколько слов он всего пережил; «жизни» — сколько времени прошло внутри мозга; «новых синапсов выросло» — сколько бесполезных связей заменилось новыми.

## Анатомия

```text
 ухо (по буквам) ──► слуховая кора ──► ассоциативная кора ──► моторная зона ──► рот
                      (звучание)    ─╮  (места слов)             (речь)
                                     ╰► узнавание: звучание → место слова (учится по совпадению)
                                          │  ▲  ▲
                                          │  │  └── место → место: STDP + дофамин; синапсы растут на неожиданном переходе
                                          ▼  │
                                    префронтальная кора (места слов: рабочая память 3–4 слова)
                                          └── → ассоциативная: контекст (без текущего слова) × кандидаты

 лимбическая зона (группы клеток чувств) ──► смысл: «слова о чувствах» (в ожидание не входит)
 VTA (дофамин) и голубое пятно (норадреналин): ядра из нейронов, залп на неожиданное слово
```

- **У каждого слова своё место**: при первой встрече слово получает 16 наименее занятых клеток смысловой коры и столько же в рабочей памяти (`brain/concepts.py`, как клетки понятий). Слово будит ровно своё место — новое знание не стирает старое (см. [DESIGN.md](docs/DESIGN.md#у-каждого-слова-своё-место-понятия)).
- **Ухо слышит по буквам**, без правил какого-либо языка. Что «франция» и «франции» — одно, мозг узнаёт сам: незнакомая форма будит знакомое место.
- **Синапсы растут там, где нужны**: на неожиданном переходе A → B к месту B прорастают связи от места A и от контекста.
- **Рабочая память** держит места последних 3–4 слов (устойчивая активность ПФК). Контекст — то, что было до текущего слова, он выбирает среди кандидатов текущего слова («солнце является → звездой»).
- **Dopamine = ошибка предсказания** — доля выстреливших клеток дофаминового ядра. Сбывшееся ожидание даёт 0, поэтому выученное перестаёт перестраивать сеть.
- **Окно STDP** сбалансировано и сдвинуто: растут только причинные пары «конец слова A → начало слова B».
- **Конец фразы** — событие со своим местом: мозг учит, где мысль кончается, и замолкает на нём.
- **Структурная пластичность**: ослабший до нуля синапс отмирает, вместо него растёт новый.
- **Зоны** заданы графом в `brain/config.py` (`default_areas`, `default_pathways`); новая зона — ещё один `AreaSpec`.

## Как учить

Обычный разговор и есть обучение. Каждая реплика проживается как опыт с dopamine от ошибки предсказания. Затем мозг отвечает, продолжая своё состояние.

| Что | Как |
|---|---|
| поощрить ответ | кнопка «Верно» (или `+`) — врождённая награда, как улыбка |
| ослабить ответ | кнопка «Неверно» (или `-`) |
| дать прочитать данные | `/read путь [проходов]`: файл или папка, любые текстовые файлы; в браузере кнопка «Дать прочитать файл» |

Похвала работает как distal reward: выброс dopamine закрепляет eligibility traces тех переходов, которые мозг только что произнёс.

**Слова похвалы мозг учит сам.** Заготовленных «молодец/нет» нет: напиши «молодец» и нажми «Верно» несколько раз — миндалина свяжет слово с наградой, и дальше «молодец» сам вызовет дофамин (под ответом: «понял похвалу»). Так же с руганью.

**Уверенность.** Мозг сам учится, насколько ему верить: при чтении он сверяет ожидание с тем, что пришло, и копит статистику «при таком ожидании я прав в X% случаев». Под ответом видно «уверен на N%», бледные слова — неуверенные. Если уверенность ниже 15% или последнее слово незнакомо — «не знаю».

**Незнакомые слова.** Мозг спрашивает «а что такое „X“?» (про слова от 4 букв). Объяснение — обычная реплика, на ней он и учится; на объяснение он не переспрашивает.

**Сон.** Гиппокамп запоминает каждую фразу с одного раза, а во сне проигрывает их коре — один проход и сон дают не меньше, чем три прохода (замеры в [DESIGN.md](docs/DESIGN.md#гиппокамп-и-сон)). В вебе мозг засыпает сам, когда устал (накопилось 50 новых впечатлений — например, после чтения файла) и 30 секунд тихо: лицо закрывает глаза, «z z Z», в ленте коричневым курсивом идут сны, срезы вспыхивают. Спит долго — 5 проигрываний на каждое новое впечатление — и просыпается выспавшимся или когда ты напишешь; недоспанное остаётся, и он снова уснёт, когда опять устанет. Вручную — `/sleep`, при обучении — `python -m brain.train --sleep …`.

**Память диалога.** Чат мозгу заново не пересылается: он помнит разговор синапсами и гиппокампом. Похваленный ответ запоминается вместе с вопросом; `/reread [N]` — перечитать последние реплики (отруганные ответы пропускаются).

**Не поспал — забыл** (`/forget on|off`, по умолчанию включено): выученное сначала свежее и затухает (полураспад 300 фраз); во сне проигрывание закрепляет то, что в нём участвовало. Выключено — всё выученное сразу навсегда.

**Размышление** (эксперимент, `/think on`): мысль звучит «про себя», проверяющий сверяет её со смыслом вопроса, при отказе берётся другая ветка; ход мыслей виден строками `[думаю] … ✓/✗`. Пока проверка не умнее памяти, поэтому выключено по умолчанию.

**Живой режим** (переключатель в вебе, `/live on`): мозг всё время что-то делает. В тишине думает про себя — текущая мысль видна под лицом, а слова мыслей бледным курсивом в ленте; иногда заговаривает сам и ждёт ответа. Заготовок нет: «прислушавшись к себе», он говорит то, что его чувство будит через выученные связи. Пока он не слышал слов о своих чувствах — молчит или лепечет; скажи ему «тебе скучно», когда ему скучно, — и в следующий раз он скажет это сам. Твоё сообщение прерывает всё это.

**Чувства** — пятая зона, лимбическая система: у каждого чувства своя группа нейронов, связи «чувство → слова» учатся, как все остальные.

**Вспоминание разговора.** Перед ответом мозг вспоминает последние реплики (гиппокамп реактивирует их следы, они подталкивают ответ) — чат ему заново не подаётся. Ответ на его собственный вопрос «что такое X?» — для него награда: объяснение закрепляется сильнее и запоминается вместе с вопросом.

**Фоновое чтение.** В вебе `/read` и «Дать прочитать файл» ставят текст в очередь: мозг читает порциями и между ними отвечает тебе.

**Эмоции** (`/mood`, `/emotions on|off`, переключатель в вебе) — из сигналов мозга и потребностей: удивление — норадреналин, радость — похвала и сбывшиеся ожидания (к угадыванию привыкают), растерянность — «не знаю», скука — голод по новому, злость — ругань, когда был уверен. Влияют на обучение (в возбуждении запоминает сильнее, эмоциональное дольше помнит) и на смелость ответа (в радости смелее, после ругани осторожнее). Под лицом — шкалы потребностей.

**Слово выбирается по вероятности**: сильный кандидат почти всегда побеждает, близкий второй иногда тоже — ответ не повторяется слово в слово. Экзамен и пробы берут лучшего.

**Микроскоп**: наведи на клетку — карточка нейрона (на какие слова отвечает, что предсказывает, кто его будит, синапсы); клик — закрепить. Чат тянется в ширину за левую границу; окошко «Мысли» показывает размышление по шагам.

Наблюдение **не меняет мозг**: `/predict`, `/continue`, `/compare`, `/debug`, `/debug_association`, `/stats`. Они выполняются в `frozen()`: пластичность выключена, состояние нейронов после пробы восстанавливается.

```text
Ты: /read train-data.md 3
Ты: /predict столица германии
после «столица германии» мозг ожидает:
  берлин               0.156
Ты: /compare открыть файл | закрыть файл
сходство контекста (prefrontal):    0.33   (1.0 = контексты не различаются)
```

## Скорость (RTX 4050 Laptop, 6 ГБ)

Симуляция событийная: на шаге обрабатываются только синапсы нейронов, которые выстрелили. 10 шагов по 1 мс записаны в CUDA Graph и запускаются одной командой.

| размер | нейронов | синапсов | GPU | чтение |
|---|---|---|---|---|
| small | 20 000 | 3.8 млн | 0.3 ГБ | 60–90 ток/с |
| medium | 100 000 | 19 млн | 1.4 ГБ | ~25 ток/с |
| — | 300 000 | 57 млн | 4.2 ГБ | 9–12 ток/с (максимум для 6 ГБ) |
| large | 500 000 | 95 млн | ~7 ГБ | не влезает в 6 ГБ |

Для сравнения: человек читает 4–5 слов в секунду.

Синапс сейчас занимает около 28 байт: индексы, вес и eligibility в fp32 плюс event-таблицы. С fp16/int8-квантизацией выйдет около 10–12 байт, то есть примерно 1 млн нейронов на 6 ГБ. Человеческий мозг (86 млрд нейронов, ~10¹⁴ синапсов) это примерно 100+ ТБ даже по байту на синапс.

## HTTP API

Совместим с OpenAI и llama.cpp — подключается любой клиент (Open WebUI, SillyTavern, curl). Веб-интерфейс тоже работает через эти ручки; WebSocket `/ws` — только живая активность нейронов.

| ручка | что делает |
|---|---|
| `POST /v1/chat/completions` | диалог: мозг учится на реплике и отвечает (`stream: true` — SSE по словам) |
| `GET /v1/models` | сохранённые мозги как «модели»; `model` в запросе переключает мозг |
| `POST /completion` | продолжить текст **без обучения** (`learn: true` — с обучением) |
| `GET /health` | готов ли мозг |
| `GET /api/state` | состояние, эмоции, выученное, анатомия |
| `GET /api/neuron/{i}` | карточка нейрона: на какие слова отвечает, что предсказывает, кто его будит, синапсы |
| `POST /api/command {text}` | любая команда чата: `/predict`, `/stats`, `/compare`… |
| `POST /api/read {name, text, background}` | прочитать текст (обучение); `background: true` — в очередь, не блокируя чат |
| `POST /api/feedback {reward}` | `1` — похвала, `-1` — ругань |
| `GET /api/brains`, `POST /api/load {name}` | список мозгов, переключение |
| `POST /api/emotions {enabled}` | включить / выключить эмоции |
| `POST /api/thinking {enabled}` | размышлять перед ответом |
| `POST /api/live {enabled}` | живой режим; реплики мозга «от себя» приходят по WebSocket (`initiative`) |
| `POST /api/stop` | остановить чтение |

```bash
curl -s localhost:8000/v1/chat/completions -H 'content-type: application/json' \
  -d '{"messages":[{"role":"user","content":"Столица Франции"}]}'
```

В ответах есть расширение `brain`: уверенность каждого слова, эмоция, dopamine, сколько слов мозг угадал.

## Переключатели

Все параметры — в `brain/config.py` (у каждого комментарий, откуда число); сохраняются вместе с мозгом. Старые сохранённые мозги открываются со старыми механизмами (новые флаги для них выключены).

| Флаг | По умолчанию | Что делает |
|---|---|---|
| `concepts_enabled` | вкл | у каждого слова своё место в смысловой коре (выкл — случайная проводка «слух → смысл») |
| `ear_letters` | вкл | ухо слышит слово по буквам (выкл — слово как случайный хэш) |
| `memory_places` | вкл | рабочая память хранит места последних слов |
| `grow_on_surprise` | вкл | синапсы растут на неожиданных переходах |
| `context_gain`, `context_mode` | 2.0, `gain` | вклад контекста: умножает кандидатов текущего слова |
| `priming_gain` | 1.0 | прайминг темы: недавние слова легче всплывают (0 — выкл) |
| `sentence_end` | вкл | конец фразы — событие, на нём мозг замолкает |
| `connected_text` | выкл | фразы одного текста не обрываются (замер: пока хуже) |
| `memory_rest_decay` | 0 | память между фразами (0 — каждая фраза с чистого листа) |
| `forgetting_enabled` | вкл | свежее затухает без сна (`/forget on|off`) |
| `nap_while_reading` | вкл | при долгом чтении засыпает по усталости и читает дальше |
| `nuclei_enabled` | вкл | дофамин и норадреналин из ядер-нейронов (выкл — формулы) |
| `emotions_enabled` | вкл | эмоции (`/emotions on|off`) |
| `arousal_plasticity`, `valence_boldness` | 1.0, 0.5 | влияние возбуждения на запоминание и настроения на смелость (0 — выкл) |
| `speak_temperature` | 0.05 | случайность выбора слова в разговоре (0 — всегда лучшее) |
| `thinking_enabled` | выкл | размышление с проверяющим (`/think on`) |
| `live_mode` | выкл | живой режим (`/live on`) |
| `structural_plasticity_enabled` | вкл | отмирание и рост слабых синапсов |

## Файлы

- `brain/engine.py`: GPU-симулятор (зоны, event-driven синапсы, STDP/dopamine, гомеостаз, структурная пластичность, `frozen()`).
- `brain/language.py`: ухо, readout, ожидание, dopamine от ошибки, диалог, чтение, диагностика.
- `brain/mind.py`: мозг целиком, сохранение и загрузка, калибровка.
- `brain/commands.py`: команды, общие для терминала и веба.
- `brain/limbic.py`: эмоции и потребности.
- `brain/concepts.py`: места слов (понятия).
- `brain/neuron.py`: карточка нейрона (`GET /api/neuron/{i}`).
- `brain/evaluate.py`: экзамен.
- `brain/hippocampus.py`: эпизодическая память и сон.
- `brain/chat.py`, `brain/server.py`, `brain/api.py`: терминальный чат, веб-сервер, HTTP API.
- `brain/train.py`, `brain/datasets.py`: обучение в фоне, подготовка диалоговых данных.
- `brain/config.py`: все параметры с объяснением, откуда взялось каждое число.
- `web/`: интерфейс на React + TypeScript (Vite): срезы зон, схема путей, лента слов с dopamine, лицо, чат.
- `tests/`: тесты.
