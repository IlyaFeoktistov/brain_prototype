# Анатомический мозг — спайковая сеть на GPU

Модель мозга из спайковых нейронов, где каждая часть — нейроны, связи и
химия по данным о мозге, без решений кода. Симулятор на PyTorch и CUDA:
нейроны AdEx/LIF, синапсы-проводимости, доставка спайков по событиям,
пластичность STDP → след → вес по третьему фактору (дофамин, ацетилхолин,
лазающее волокно). Знания — только в весах синапсов.

Дальняя цель — мозг, который учится у мира и разговаривает как
чат-ассистент. **Пока он не разговаривает.** Ниже — честно: что уже
работает, что нет и что вы увидите, если запустите.

- [ROADMAP.md](ROADMAP.md) — цель, звенья до неё и что их держит.
- [docs/DESIGN.md](docs/DESIGN.md) — решения и замеры;
  [docs/SPAUN_TRANSFER.md](docs/SPAUN_TRANSFER.md) — текущая основная
  линия; [docs/ISSUES.md](docs/ISSUES.md) — открытые находки и все
  известные заглушки.

## Состояние (2026-11-18)

### Работает, измерено

- **Мозг целиком идёт на одной видеокарте 6 ГБ:** по умолчанию ~320 000
  нейронов и ~183 млн синапсов — 11 зон коры (колонки по слоям), таламус,
  базальные ганглии, мозжечок, гиппокамп, миндалина, ядра модуляторов, сон
  и бодрствование. Частоты каждого ядра и слоя в покое подогнаны под
  записи у бодрствующих животных и людей.
- **Зрение до букв:** текст на экране проходит сетчатку → LGN → V1 → зону
  букв (V4/LO); клетки LGN под словом стреляют ~в 3 раза чаще фона. После
  учёбы с учителем зона букв различает 10 букв у ямки (0.58 при случайном
  0.1).
- **Веб:** создать мозг, писать в чат, смотреть все зоны вживую
  (микроскоп), карточки клеток, химию, пути, что видит глаз и куда жмёт
  рука.
- **Блоки управления рабочей памятью (E1)** — схема управления Spaun
  (Eliasmith 2012), собранная из спайковых популяций; пока отдельные
  маленькие сети, ещё не в мозге:
  - ячейка памяти (Brunel & Wang 2001) держит слово — 8/8;
  - ворота таламуса (MD под SNr) пропускают и закрывают запись как
    надо — 5 условий, 8/8 на 3 зёрнах;
  - счётчик позиции проходит 1 → 5 без ошибок — 23/24 (3 зерна);
  - запись фразы из 3 слов в память «позиция × слово», канал выбирают
    спайковые базальные ганглии — 23/24.

### Пока не работает

- **Разговора нет.** Реплику можно написать, мозг на неё смотрит, но рука
  печатает шум: моторный таламус (VA) держится на подобранном токе и
  залпами гонит карту руки, поэтому клавиши жмутся и на пустом экране
  (заглушка, ISSUES 23).
- **Вывод записанной фразы по порядку («повтори») — 3–4 из 8.** Причина
  найдена: сброс счётчика ослабляет первую позицию (SPAUN_TRANSFER, шаг 5б).
- **Нет инвариантности букв к месту:** при сдвиге на ±3 px от ямки буква
  теряется.
- **Смысл не учится:** слово → смысл на уровне случая (0.12); правило
  пластичности коры по данным человека не подобрано.
- **Премоторная → рука не показано:** ток в L5 карты руки жмёт нужную
  клавишу (16/18), команда из L2/3 и из премоторной до клавиши не доходит.
- Многие числа помечены `[сверить]`; каждая заглушка — в docs/ISSUES.md,
  раздел «Костыли и заглушки».

## Запуск

Нужны видеокарта NVIDIA (хватает 6 ГБ), Python 3.12 и Node.js (сборка
интерфейса).

```bash
python3 -m venv .venv && source .venv/bin/activate
pip install torch --index-url https://download.pytorch.org/whl/cu128
pip install -r requirements.txt
./run-web.sh            # http://localhost:8000
```

В вебе создайте новый мозг по пресету **рабочий** (`brain/presets.py`) —
тот же мозг, что в опытах: подогнанный зрительный путь и выученные буквы;
его файлы лежат в репозитории (`data/presets/`). Мозги сохраняются в
`~/.brain/brains/` (`BRAIN_HOME`).

Почему наименьший мозг ~320 000 нейронов: каждая зона коры — колонка не
меньше 20 000 клеток; в меньшей колонке почти весь вход — средний ток
вместо недостающих соседей, и сеть идёт патологическими пачками
(`min_column_neurons` в `brain/config.py`).

Блоки E1 идут на CPU:

```bash
cd tools
PYTHONPATH=. ../.venv/bin/python e1_counter.py     # счётчик позиции
PYTHONPATH=. ../.venv/bin/python e1_phrase.py      # запись фразы
PYTHONPATH=. ../.venv/bin/python e1_recall.py      # вывод по порядку (пока не работает)
```

## Как мозг общается с миром

Чат — как переписка в мессенджере: мир рисует текст на экране, мозг читает
его глазом и печатает ответ рукой на клавиатуре. Куда посмотреть, что
понять и что нажать — решает сеть; код — только тело и мир (сетчатка,
клавиатура, экран, вкус-награда учителя). Голос — через ухо (улитка).

```
                ЭКРАН (мир)                         ГОЛОС (мир)
                    │                                    │
              сетчатка ON/OFF                     улитка, слуховой нерв
                    │                                    │
                   LGN ◄── ретикулярное               кохлеарное ядро (CN)
                    │                                    │      └► VNLL ┐
           V1: простые (L4) → сложные (L2/3)       нижнее двухолмие (IC) ◄┘
                    │                                    │
          зона букв (V4 / LO)                       MGN ◄── ретикулярное
                    │                                    │
                    └──────────►  СМЫСЛОВАЯ КОРА  ◄──── слуховая кора (A1)
                                (ассоциативная)  ◄────► речевая моторная (Брока)
                                 ▲    ▲    ▲
             ПФК и цель ◄────────┘    │    └────────► височный полюс (категории)
             (MD таламуса)            │
                                гиппокамп: EC → DG → CA3 ↺ → CA1
                    │
     смысл → буквы → зона Экснера (премоторная) → моторная кора руки → КЛАВИШИ
                         ▲          │                     ▲
                         │          └► базальные ганглии ─┤ (выбор действия:
                         │             стриатум D1/D2, GPe,│  «нажать / ждать»)
                         │             STN, GPi ⊣ VA/VL ───┘
                         │
                 мозжечок: мшистые волокна → гранулярные → Пуркинье ⊣ ядра → VLp
                 (учится по ошибке: нижняя олива — лазающие волокна)

     Взгляд: боковое зрение и V1 → верхнее двухолмие (⊣ GPi) → саккада
```

Химия и состояния:

```
  VTA (дофамин) ◄─ вкус «сладко»; уздечка ⊣ VTA ◄─ вкус «горько», GPi
  голубое пятно (норадреналин), шов (серотонин), ядро Мейнерта (ацетилхолин),
  латеральный гипоталамус (орексин)
  сон: VLPO ⊣ ядра бодрствования; аденозин копится наяву; часы SCN → DMH
  миндалина: смысл → базолатеральная → центральная ⊣ LC, VTA, Мейнерт
```

Каждая зона коры — колонка по слоям (L2/3, L4, L5, L6): вход из таламуса и
низших зон — в L4, связи с соседями — L2/3, выход к ядрам и мышцам — L5,
обратная связь в таламус — L6. Вещества действуют через рецепторы: выброс
ядра — концентрация — занятость рецепторов — ток клеток.

## Файлы

- `brain/anatomy.py` — зоны, пути, ядра, рецепторы и данные человека со
  ссылками на исследования.
- `brain/config.py` — параметры клеток, колонки, пластичности, химии,
  органов (у чисел — источники).
- `brain/engine.py` — симулятор; `brain/csrc/events.cu`, `brain/kernels.py`
  — ядра CUDA.
- `brain/mind.py` — мозг целиком: сборка, сохранение, загрузка.
- `brain/body.py`, `brain/world.py`, `brain/session.py` — тело, мир и
  разговор с миром.
- `brain/presets.py`, `data/presets/` — готовые сборки мозга.
- `brain/server.py`, `web/` — веб.
- `tools/` — стенды и опыты (`e1_*.py` — блоки управления рабочей
  памятью).
