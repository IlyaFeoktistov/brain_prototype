- [x] Медленная тема (второй масштаб контекста): прошлые фразы предлагают кандидатов — факты 24 → 27, тема в разговоре держится 3/3 и после посторонних реплик

- [x] Смысловая кора — карта: место слова компактно и встаёт рядом со словом, после которого прозвучало («районы смысла» видны в микроскопе)
- [x] Микроскоп: рост синапсов виден дугами (слово → слово, контекст → слово, слово → миндалина); выбор каждого слова с вероятностями — в окошке «Мысли»
- [x] Миндалина учится, какие слова предвещают похвалу или ругань, и мозг огорчается или радуется заранее
- [x] Тонический фон дофамина: похвала — залп клеток VTA, ругань — пауза ниже фона (всё через ядро)
- [x] Путь «память → смысл» учится по совпадению под дофамином (STDP при непрерывной активности памяти не учил): контекст → конец фразы 0.13 → 2.93, ответы короче
- [x] К хорошему привыкают: угаданное слово радует тем меньше, чем привычнее угадывание — настроение не упирается в 1.0, ругань огорчает
- [x] Конъюнкция «X, потом Y»: контекст — то, что было до текущего слова («солнце является → звездой», «луна вращается вокруг → земли»)
- [x] Конец фразы — событие со своим местом: мозг учит, где мысль кончается, и замолкает на нём
- [x] Уверенность: шкала под резкие ожидания, без «одна удачная проверка поднимает всех»
- [x] Прайминг темы: недавно звучавшие слова легче всплывают среди кандидатов (×, не +)
- [x] Слово в разговоре выбирается по вероятности (близкие кандидаты иногда побеждают) — не повторяет ответ слово в слово; экзамен и пробы — лучший
- [x] Рабочая память хранит места последних слов (устойчивая активность ПФК), контекст включён (gain): факты 25/36 первым словом (утром ~10)
- [x] Ухо слышит слово по буквам (без правил языка); узнавание звучания учится по совпадению — незнакомые формы («францию») будят знакомое место («франции»)
- [x] Синапсы растут там, где нужны: на неожиданном переходе A → B прорастают связи от места A к месту B («италии → рим»: 0 → 15 синапсов)
- [x] У каждого слова своё место (понятия): новое не стирает старое — после статьи-помехи факты на 1–5 месте вместо 433–866
- [x] Долгое чтение спит по усталости: 100 новых впечатлений — поспать и читать дальше (CLI — внутри чтения, веб — между порциями, будится сообщением)
- [x] Эмоции как в мозге, шаг 2: дофамин и норадреналин — доля выстреливших клеток ядер VTA и голубого пятна; привыкание LC из адаптации клеток
- [x] Эмоции как в мозге, шаг 1: потребности (голод по новому, одобрение, фрустрация) — скука от монотонности и тишины, злость от ругани при уверенности, похвала слаще, когда её ждёт; шкалы под рожицей
- [x] Чат тянется в ширину; окошко «Мысли» — ход размышления и блуждания по шагам с вердиктами проверяющего

## Очередь — по критичности

Порядок: сначала то, что ломает или блокирует главное (мозг учится из
разговора и данных и отвечает), потом правильность памяти и сна, потом
эмоции как в мозге, наблюдаемость, масштаб и новые чувства. Большие
прогоны и подбор чисел — после архитектуры.

### P0 — критично: ломает обучение или не даёт ему поумнеть

- [x] Ответ нейронами (по умолчанию): ворота «говори» (ровный ток на смысловую кору, слабеют после каждого своего слова), слово — выстрелившее место, никто — «не знаю», «.» — конец мысли; контекст на дендритах (конъюнкция в нейроне); своя речь не вытесняет вопрос из памяти. Факты 26 / 21 против 25 / 24 у формулы (2 зерна). Без `decode`, порогов резкости/уверенности и исключения слов кодом. Блуждание мыслей и инициатива — тем же путём
- [ ] Ответ нейронами на 20 тыс. нейронов: 9–16 фактов из 36 против 27 у формулы — контекст на дендритах размазан, «X является» отвечает частым продолжением (DESIGN «Ответ нейронами на 20 тыс.»). На 100 тыс. — паритет. [замер] подготовка ответа в спайках втрое слабее: ток места ответа 3–5 при фоне 2.5 (на 100 тыс. — 8–15); формула этого не видит — читает веса напрямую
- [ ] Мозг целиком из нейронов, без if-else: решения, которые сейчас принимает Python, — по одному в нейроны, каждое с замером на экзамене. Осталось кодом (✓ — уже нейронами): ✓ (1) выбор слова — `decode` (косинус ожидания с местами всех слов) → места слов конкурируют через взаимное торможение (k-WTA спайками), победитель будит рот; ✓ (2) говорить или молчать — пороги `generate_min_score` / `generate_min_margin` / уверенность → базальные ганглии (стриатум D1 «давай» / D2 «стой», ворота через таламус, учатся дофамином); (3) уверенность — таблица «при такой резкости прав в X%» → сила и скорость победы в конкуренции (метапознание ПФК); (4) рот только отражает выбранное слово → моторная зона сама произносит, своё слово слышно через ухо; ✓ (5) конец мысли — слово END и `break` → затухание, когда цель в ПФК выполнена; (6) тема, прайминг, категории, закрытие — множители в `expectation` → входы зон (в ответе нейронами их сейчас нет вовсе — только то, что течёт по синапсам); размышление (`/think`) — ещё формулой; ✓ первое слово инициативы — чувство активно, ворота открыты без звука, выстрелившее место; (7) засыпание по счётчику впечатлений → давление сна (аденозин) как медленная переменная в нейронах; (8) живой режим: «когда думать» (таймер `wander_every_seconds`), «когда заговорить» (порог `initiative_urge` + таймеры), «когда заснуть» (порог давления сна) — код; в тишине мозг не живёт, симуляция запускается по таймеру. Нужно: мозг крутится непрерывно со спонтанной активностью, мысль всплывает сама при открытых воротах, порыв говорить — через базальные ганглии, сон — переключатель в нейронах (VLPO ↔ ядра бодрствования); (9) ошибка предсказания для обучения — сделано под флагом `neural_surprise` (подготовленность мест по потенциалу; 100 тыс., seed 42: 24 = 24 у формулы; seed 7: 19–21 против 24 — не включено, средний потенциал места — слабый предсказатель, DESIGN «Неожиданность из нейронов»). Пример цены ручного решения: резкость по списку без нулей — большой мозг молчал при верном лидере (см. DESIGN «Резкость ожидания…»). [замер] предсказание в сети есть ниже порога (место ответа −56…−63 мВ против −67.5); сигнал «говори» +16 мВ во время последнего слова — спайками 10/26 фактов против 19/26 у формулы, выше 19 мВ зона взрывается (DESIGN «Выбор слова нейронами»). Шаги: (а) конкуренция мест — торможение растёт с возбуждением; (б) контекст как конъюнкция, а не сумма; (в) привыкание выстрелившего места вместо исключения слов кодом; (г) ворота «говори» из базальных ганглиев

- [ ] Ёмкость — главный ограничитель ума: прогон 20 мин на вопрос→ответ (9.4 тыс. слов при ~4800 местах medium) стёр половину фактов и зашумил ответы. Нужно: (а) больше мест на той же памяти — квантизация, процедурная проводка (из P4); (б) места переиспользуются для редких слов / растут по мере нужды; (в) учебный план — сначала частые слова (мини-словарь), редкие имена потом; (г) слово = место корня + место окончания (оба активны): корни и окончания мозг выделяет сам из статистики букв (как Morfessor, без правил языка); стеммер «одно место на основу» уже проверен — хуже, окончание несёт смысл. Размер для обучения на 6 ГБ — 250 тыс. нейронов (~34 тыс. мест): large после сборки таблиц кусками создаётся, но при чтении пик 6.46 ГБ, 0.9 слова/с

- [ ] Цель разговора (ситуационная модель, ПФК как рабочее пространство): группа клеток «цель» держит места слов вопроса, пока ответ не совпал с тем, куда они толкали; цель выполнена — гаснет, мозг замолкает. Лечит уплывание после верного ответа. Попытки: (а) «стоп, когда сказано предсказанное вопросом» — не отличает «париж» от «вокруг» (оба 1-е в цели); (б) закрытие — «конец» поддерживает вся память (`closure_gain`) — вход памяти в «конец» слабый (0.3 против 10), помогает «рим.», ломает «человек живёт»

- [ ] Рабочая память: конъюнкция работает («солнце является → звездой»), но контекст держится 3–4 слова и не помогает уплыванию после верного ответа («столица франции → париж франция находится…»)
- [ ] Генерация уплывает после верного слова. Причины: (1) запрет повторять слова вопроса (`repeat_prompt_words` выкл — иначе эхо собеседника); (2) общее слово контекста («является») накачано к одному продолжению («испании» 8.1 против «франции» 0.9) и перебивает конкретное («париж → франции» 0.7). Обучение на ошибке идёт в одну сторону: верное продолжение перестаёт учиться, неверное копится; ослабление ожидавшегося не помогло. Нужна нормировка вклада частых слов контекста
- [ ] Переход через «.»: оба наивных варианта хуже (память 0.5: угадано 303 → 210, факты 24 → 21; память 0 + прайминг: факты 24 → 19)

### P1 — важно: память и сон работают правильно


- [ ] Забывание без сна: подобрать полураспад и силу закрепления (маленьким замером)
- [ ] Эпизодическая память как контекст в разговоре (длиннее 6 слов рабочей памяти)
- [ ] Сон: приоритет неожиданных фраз хуже, чем поровну — застревает на трудных; >5 проигрываний на фразу — переучивание
- [ ] Давление сна от объёма новых впечатлений → сонливость → засыпание (сделано базово, уточнить)
- [ ] Пробы начинаются после секунды тишины — состояние отличается от живого чтения (искажает замеры)
- [ ] Размышление: проверяющий помогает мало (5 → 6 из 14) и не умнее памяти; выключено по умолчанию
- [ ] Проверяющий как популяция нейронов ПФК; ПФК как рабочее пространство (цель, текущая мысль, конфликт)
- [ ] Внутренняя награда от проверяющего (± дофамин) — учиться на своих ошибках при размышлении

### P2 — эмоции как в мозге


- [ ] Ядро шва (серотонин): фон настроения из нейронов вместо формулы
- [ ] Миндалина: ценность сейчас читается по синапсам, а не спайками (слишком мало синапсов от места слова) — дать миндалине выстреливать; «злость как заблокированная цель» — пока через фрустрацию-формулу
- [ ] Эмоции в подаче ответа, остальное: растерянность — переспрашивает, любопытство — больше вопросов, скука — тянет к новому
- [ ] Эмоциональные эпизоды чаще проигрываются во сне (осторожно: приоритет по значимости уже проигрывал «поровну»)
- [ ] Чувство и слова связываются со всем, что мозг пережил в этом чувстве, — специфичность только через то, когда человек говорит о чувстве
- [ ] Эмоция всё ещё отчасти модель поверх сигналов; коэффициенты влияния (`arousal_plasticity`, `arousal_salience`, `valence_boldness`) не подобраны

### Эксперименты: вещества (фармакология)

- [ ] «Аптечка»: дать мозгу вещество и смотреть, как он читает, отвечает, чувствует и спит. Вещество = на что действует в модели (рецепторы → параметры нейронов и ядер), доза, фармакокинетика (начало действия, пик, период полураспада) — концентрация во времени множит свои параметры. Готовые пресеты + свои в конфиге (`substances`), панель в вебе (дать / доза / кривая концентрации поверх графиков активности), `/take кофеин 1` в чате, отметки на ленте. Пресеты (действие — через модель, не заготовки поведения):
  - кофеин — антагонист аденозина: давление сна ниже, возбудимость коры выше, шум чуть выше; начало ~20 мин, полураспад ~5 ч
  - снотворное (бензодиазепин) — сильнее ГАМК-A: торможение ×1.5, ворота «говори» туже, засыпает быстрее
  - алкоголь — ГАМК↑ и NMDA↓: дендритное плато и рабочая память слабее, гиппокамп запоминает хуже, смелость ответа выше
  - кетамин — блок NMDA: медленный ток и плато почти исчезают — контекст и рабочая память рвутся
  - L-DOPA / амфетамин — дофамин↑: обучение сильнее, ворота шире (говорит больше и смелее, больше ошибок)
  - галоперидол — блок D2: дофамин не учит, ворота уже — вялость, «не знаю»
  - никотин — ацетилхолин↑: внимание и пластичность (после ядра базального переднего мозга)
  - пропранолол — блок норадреналина: эмоциональные эпизоды не усиливаются
  - SSRI — серотонин (после ядра шва)
  Замер для каждого: экзамен, скорость обучения, «не знаю», настроение, сон — до / на пике / после выведения

### Чего не хватает до полной модели мозга

Сверка с тем, что есть в настоящем мозге (по важности для речи и обучения):

- [ ] Базальные ганглии — выбор действия и ворота «говорить / молчать», обучение привычек дофамином (см. P0 «без if-else»)
- [ ] Таламус — ворота внимания между зонами, ритмы; кора ↔ таламус как главный канал обмена
- [ ] Слоистая кора: слои 4 (вход), 2/3 (связи между зонами), 5 (выход), 6 (обратная связь) — предсказание сверху вниз и ошибка снизу вверх как разные пути, а не одна формула
- [ ] Гиппокамп из нейронов (сейчас хранилище фраз, P3): зубчатая извилина (разделение похожего), CA3 (достраивание по части), CA1; острые волны с рябью — проигрывание во сне
- [ ] Ритмы: тета/гамма (порядок слов в рабочей памяти), веретёна и медленные волны сна — окно переноса из гиппокампа в кору
- [ ] Нейромодуляторы как ядра из нейронов: голубое пятно (норадреналин — сейчас формула возбуждения), базальные ядра переднего мозга (ацетилхолин — внимание и сила пластичности), ядро шва (серотонин, P2); дофамин VTA уже есть
- [ ] Мозжечок — предсказание последовательностей и тайминг (ритм речи)
- [ ] Кратковременная пластичность синапсов (облегчение / истощение за сотни мс) — рабочая память без постоянного тока
- [ ] Дендриты: несколько компартментов, NMDA-плато — нейрон узнаёт сочетания входов (конъюнкция без отдельных клеток)
- [ ] Тело изнутри: интероцепция, гомеостаз (голод, усталость) как источник потребностей вместо формул; циркадный ритм
