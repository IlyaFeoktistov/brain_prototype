# Курс: от азбуки до вопросов

Учебная программа мозга по порядку номеров — как у ребёнка: азбука →
слоги → слова → фразы → предложения → факты о мире → вопросы о них.
Каждый следующий файл опирается на предыдущие (в ответах 07 — только то,
что было в 05 и 06).

Первая строка файла — как учитель его показывает (`tools/train_anatomy.py
stage=course`):

- `# шаг: letter` — указка под каждой буквой;
- `# шаг: syllable` — по слогам (слово — открытый слог до гласной);
- `# шаг: word` — по словам;
- `# шаг: qa` — `вопрос | ответ`: учитель спрашивает, мозг отвечает рукой,
  верно — сладкое, нет — горькое.

Остальные строки с `#` — пояснения. В `03-слова` перед двоеточием — буква,
к которой относятся слова (учитель показывает только слова).

Новый файл — следующий номер; вставка между — переименовать хвост.
