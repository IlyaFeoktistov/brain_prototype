# Архитектура: цель и где мы сейчас

Чертёж мозга целиком. Правило проекта: **вместо формул и ручной
подкрутки — базовые правила, как в настоящем мозге**; поведение должно
вырасти из них. Здесь — какая структура нужна, что уже сделано
нейронами, что пока костыль в коде и чем его заменить. Порядок работ —
в конце; почему каждое число такое — в [DESIGN.md](DESIGN.md).

Метки: ✓ — нейронами, как в мозге; ~ — частично (структура есть,
решение или чтение — кодом); ✗ — код вместо нейронов (костыль).

## 1. Клетка

| Что | В мозге | У нас | |
|---|---|---|---|
| Пирамидная клетка | AdEx: порог, адаптация, всплеск | AdEx, адаптация 1 мВ / 150 мс | ✓ |
| Дендрит с плато | NMDA-плато умножает вход сомы (конъюнкция) | один дендритный ток от ПФК (`dendritic_context`) | ~ |
| Тормозные клетки | PV (быстрое, пропорционально соседям), SST (дендриты, гасят «чужой» вход), VIP (растормаживают по вниманию) | один тип — быстрый LIF | ✗ → три типа |
| Рабочая память | устойчивая активность на NMDA | медленный ток τ 400 мс + **след, который держит код** (`memory_mv × memory_decay`) | ~ |
| Гомеостаз возбудимости | клетка двигает порог к своей норме | смещение `bias` по зонам; у смысловой коры выключен | ~ |

## 2. Синапс

| Что | В мозге | У нас | |
|---|---|---|---|
| STDP → след → дофамин | трёхфакторное правило | есть (`eligibility`, залп дофамина) | ✓ |
| Свежее и закреплённое | early-LTP затухает, сон закрепляет | `early`, `forget`, захват во сне | ✓ |
| Кратковременная пластичность | истощение / облегчение за сотни мс | истощение в смысловой коре (`base_circuit`); облегчения нет | ~ |
| Пластичность торможения | iSTDP: клетка выше нормы — больше торможения | на уровне клетки, не синапса (`base_circuit`) | ~ |
| Гомеостаз синапсов | масштабирование по частоте клетки | бюджет суммы раз в 20 фраз | ~ |
| Рост / отмирание | по активности | рост на неожиданности — **кодом решается, куда** | ~ |
| Ослабление во сне | все синапсы ×(1−ε) за ночь (Тонони) | выученный прирост × (1 − 0.0004) за проигрывание (`base_circuit`) | ✓ |

## 3. Микроконтур коры

Каждая зона коры в мозге — повторяющийся контур со слоями:

```text
   слой 2/3  ── связи между зонами (ожидание вверх по иерархии)
   слой 4    ◄─ вход (от таламуса / зоны ниже)
   слой 5    ─► выход (рот, подкорка, базальные ганглии)
   слой 6    ─► обратная связь в таламус (предсказание сверху вниз)
   PV · SST · VIP — торможение в каждом слое
```

У нас: зона — одна популяция E + одна I, без слоёв. Предсказание и
ошибка идут одной формулой (`expectation`, `learned_drive`), а не
разными путями (✗). Это крупный шаг, его — после стабилизаторов
и стенда.

## 4. Зоны и пути

| Зона | Роль | У нас | |
|---|---|---|---|
| Глаз + зрительная кора (V1 → V4 → VWFA) | читает текст: сетчатка видит картинку слова, V1 — штрихи, детекторы букв с позицией, форма слова (Dehaene et al. 2005) | нет: текст входит через «ухо по буквам» | ✗ |
| Ухо + слуховая кора | звук речи: улитка — частотные каналы, звуки и слоги | **буквы, а не звук** (символ → каналы по хешу) | ✗ |
| Смысловая (ассоциативная) кора | места слов, связи между ними | места **выделяет код** (`Concepts`: ближайшие свободные клетки) | ~ |
| ПФК (рабочая память, цель) | держит контекст и цель | места слов в ПФК, след кодом; цели нет | ~ |
| Рука (дорсальная премоторная, зона Экснера) + графемный буфер | печатает текст, как в мессенджере: буквы слова в буфере параллельно с позицией, по одной на клавишу (~150–250 мс) | «рот по буквам» (фактически рука, но на механизмах рта и сжатом времени) | ✗ |
| Рот (вентральная моторная кора) | произносит звуки: жесты губ, языка, гортани (Bouchard 2013) | нет (буквенный «рот» — это рука) | ✗ |
| Височный полюс (категории) | обобщение по ролям | **решения о членстве принимает код** (`_learn_categories`), синапсы растут по ним | ✗ |
| Лимбическая система | чувства, модулируют усиление | группы клеток на чувство; **само чувство — формула** (`Emotions`); путь в смысл **гонит ток в места слов** вместо модуляции (`/trace`) | ~ |
| Миндалина | хорошо / плохо | клетки есть; ценность читается по синапсам кодом | ~ |
| Таламус | ворота внимания, ритмы, канал между зонами | нет | ✗ |
| Базальные ганглии | выбор действия: говорить / молчать / исследовать | ворота «говори» — **ровный ток из кода** (`speak_gate_mv`, убывает ×0.95) | ✗ |
| Гиппокамп | эпизоды с одного раза, проигрывание во сне | **список фраз в Python**, во сне фраза подаётся через ухо | ✗ |
| Мозжечок | тайминг, ритм речи | нет | ✗ |

## 7. Стабилизаторы — без них ансамбли замыкаются

У мозга несколько механизмов на разных масштабах времени; у нас был
один, и частые слова замкнулись в эпилептический очаг (DESIGN «Ёмкость:
обвал после чтения»). Базовый контур должен включать все сразу:

| Механизм | Время | У нас |
|---|---|---|
| Торможение, растущее с возбуждением (PV) | мс | пул торможения есть, выключен (`pool_inhibition_mv` 0) |
| Пластичность торможения (iSTDP) | секунды–минуты | на уровне клетки (`base_circuit`) |
| Кратковременное истощение синапсов | сотни мс | есть (`base_circuit`) |
| Адаптация клетки | сотни мс | есть (слабая: 1 мВ) |
| Адаптация сенсорного входа (и чувства) | секунды | чувство — есть (`interoception_adapt_ms`) |
| Гомеостаз синапсов | минуты–часы | бюджет раз в 20 фраз |
| Ослабление во сне | ночь | есть (`base_circuit`) |

Замер контура — DESIGN «Базовый контур»: чтение 10 тыс. слов больше не
стирает факты (13 → 13, 11 → 16), очага нет.

## 8. Стенд отладки («ЭЭГ»)

Сегодня ошибки находятся разовыми скриптами. Стенд — постоянный:

1. **Показатели здоровья** после каждой фразы (дёшево, без синхронизаций
   там, где можно): частоты по зонам на слове и **в паузе** (в тишине
   кора молчит), доля активных клеток против `target_activity`,
   E/I-баланс, вход клетки относительно врождённого (макс / среднее),
   потерянные спайки, доля мест, делящих клетки. Нарушение — запись в
   журнал с фразой, где случилось.
2. **Трассировка вопроса**: по шагам, какие места слов возбуждены, какой
   ток пришёл от каждого пути (слово, контекст ПФК, категории, чувство),
   кто победил и почему — то, что сейчас делается вручную (`/debug`,
   разовые пробы).
3. **Экзамен** (`brain.measure`): факты до и после корпуса, 2 зерна.

## 9. Порядок работ

1. Стенд: показатели здоровья + трассировка (`brain/health.py`,
   `/health`, строка в `brain.measure`).
2. ✓ Базовый контур (`base_circuit`, по умолчанию): истощение синапсов,
   пластичность торможения, ослабление во сне + адаптация сигнала
   чувства; `calm_hz` убран. Дальше: PV-торможение, облегчение синапсов,
   iSTDP по синапсам, нужен ли ещё бюджет масштабирования.
3. Убрать костыли ✗ по одному, каждый со стендом и экзаменом:
   ворота «говори» → петля базальных ганглиев; рот произносит сам;
   уверенность — из конкуренции; категории без решений кодом; давление
   сна и переключатель сна — в ядрах; живой режим — непрерывная
   симуляция; гиппокамп из нейронов; заготовки фраз.
4. Слои коры и таламус (предсказание и ошибка — разными путями).
