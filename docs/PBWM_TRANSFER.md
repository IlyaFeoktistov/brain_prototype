# PBWM → E1: карта соответствия (шаг 4а)

Источник — код `emer/leabra` (ветка main, клон 2026-11-24, только чтение):
`PBWM.md`, `examples/sir2/sir2.go` (ConfigNet, параметры), `leabra/pbwm_paths.go`
(правило следа), `leabra/pbwm_layers.go` (GPiThal). Статья — O'Reilly & Frank
2006, Neural Computation 18:283–328, https://doi.org/10.1162/089976606775093909.

Зачем: на корковом входе стриатум записи E1 горит — его вход «пришло слово»
равен сумме всех слов (контраст ≈ 1.3×), FSI по данным это не лечат
(CHAT_PLAN, шаг 4а, цикл FSI). Вопрос — что подаёт вход в стриатум PBWM.

## Что делает sir2 (задача Store–Ignore–Recall)

| Звено sir2 | Что это | Вход | Чем задано |
|---|---|---|---|
| Input (A–D) | содержание (что запомнить) | — | 4 единицы |
| CtrlInput (S, I, R) | задача: запомни / не обращай внимания / вспомни | — | 5 единиц |
| PFCmnt (super) | копия текущего входа | Input 1-к-1, веса фикс. («PFCFixed») | — |
| PFCmntD (deep) | удержание | super → deep только при воротах | GateState |
| MatrixGo (D1) / MatrixNoGo (D2) | ворота: открыть / не открывать полосу | **только CtrlInput**, топографически 1-к-1 по единицам (`Rect 1×1, Wrap`), класс MatrixPath (учится) | — |
| GPeNoGo | конкуренция NoGo между полосами | MatrixNoGo | без неё «всё NoGo → ничего не учится» |
| GPiThal | выбор полосы: Ge = (GeGain + NoGo)·(Go − NoGo·NoGoIn), порог 0.25 (sir2) | MatrixGo, GPeNoGo | GeGain 3, NoGo 1.25 |
| Rew, RWPred, SNc | дофамин = ошибка предсказания награды (Rescorla–Wagner) на Recall | Ctrl, PFCmntD, PFCoutD | — |

Главное (README sir2): *«control information is all that the Matrix layer
requires. It can also learn with the irrelevant A-D inputs, but just takes a bit
longer»* — стриатум решает **когда/куда** писать по контексту задачи; **что**
писать несёт путь содержание → PFC super, избирательный сам по себе.

Время ворот в sir2 — не от прихода стимула: гейт проверяется на фиксированном
такте цикла (GPiThal.Timing: такт 18 из 25 в четверти Q1 и Q3, бета-ритм
BG–PFC ~20 Гц); один стимул = одна проба.

## Правило обучения Matrix (pbwm_paths.go, DWtMatrix)

На каждом синапсе вход → Matrix:
- новый след `ntr = f(act_post)·act_pre`, `f(a) = 2a(1 − a)` (Deriv);
  для полосы, которая открылась (GateAct > 0), — `+ntr`; для не открывшейся —
  `−0.7·ntr` (NotGatedLR);
- `tr += ntr − min(1, |ntr|)·tr` (Decay 1: новый след вытесняет старый);
- при дофамине: `dW = lrate · DA_lrn · tr`; для D2 (NoGo) знак DA обращён;
  у D2 при DA > 0 и tr < 0 — множитель 0.1 (GateNoGoPosLR: NoGo отпускает
  медленно — исследование других действий);
- lrate 0.04 (sir2), начальный разброс весов 0.1.
Биологически — синаптическая метка (Redondo & Morris 2011,
https://doi.org/10.1038/nrn2963): метка живёт до ~90 мин, захватывается
следующим сильным сигналом.

## Соответствие E1

| sir2 | E1 сейчас | Расхождение |
|---|---|---|
| CtrlInput → Matrix | позиция (pos_counts) **+ сумма всех слов** → стриатум записи | сумма слов лишняя: в PBWM содержания на входе стриатума нет (или оно — необязательная добавка, учится дольше) |
| Input → PFC super 1-к-1 | слово → реле MD канала (схождение 162 клеток) → ячейка | совпадает по смыслу; на корковом входе работает (36 Гц против 0.2–0.5) |
| такт ворот (бета, фикс.) | окна записи — расписание учителя E1 (ISSUES 28–29) | у нас время задаёт учитель — костыль уже записан |
| Go/NoGo + GPe + GPiThal | только D1 → SNr (непрямого пути, GPe нет — ISSUES 29) | нет NoGo |
| след + дофамин (RW на Recall) | весов нет, ворота заданы | нет обучения |

Вывод: **избирательность «какое слово» в PBWM не в стриатуме**, а в пути
содержания (у нас реле MD — работает). Стриатум получает контекст задачи. Наш
дефект — сумма слов на входе стриатума, которой в PBWM нет.

## Минимальный опыт (предложение)

Один шаг, без обучения: вход стриатума записи — только контекст (позиция +
состояние задачи «запоминаю», как CtrlInput «S»), без суммы слов; время — как
сейчас (окна расписания E1, аналог такта sir2); содержание — реле MD со
схождением избирательных клеток коры. Мера — испытание «БД» с картинкой
(tools/e1_in_brain.py + e1_in_brain_plot.py), затем 3 зерна.

Следующий шаг после — Go/NoGo + след + дофамин по коду выше, чтобы стриатум
сам выучил, когда писать (учитель только награждает за верный повтор).
