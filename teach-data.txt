# Разговор как учитель: python -m brain.teach
#
# вопрос | ответ учителя | перефразировка; перефразировка
#
# Ответ учителя — то, что он скажет, если мозг ошибся; верным считается
# ответ, где среди первых трёх слов есть последнее слово ответа учителя
# (с точностью до окончания). Все факты есть в train-data.md, но не в
# форме вопроса. Отложенные — прочитаны, в разговоре не спрашиваются до
# проверки после сна.
