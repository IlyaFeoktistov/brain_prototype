Вопрос может иметь ответ.
Ответ может быть правильным или неправильным.
Если человек не знает ответа, он может искать информацию.
Если человек получает новую информацию, он может изменить своё мнение.

Компьютер выполняет программы.
Программа состоит из инструкций.
Инструкция говорит компьютеру, что нужно сделать.
Данные могут храниться в памяти компьютера.
Файл содержит данные.
Текстовый файл содержит текст.
Программа может читать файл.
Программа может записывать файл.

Обработка приводит к результату.

Связь между нейронами может ослабевать.
Повторяющиеся сигналы могут укреплять связь.
Память может возникать из устойчивых связей.

Мозг обрабатывает информацию.
Мозг может предсказывать следующее событие.
Ошибка предсказания сообщает мозгу, что ожидание было неправильным.
Неожиданное событие может сильнее изменить память.
Повторяющееся событие становится более ожидаемым.
